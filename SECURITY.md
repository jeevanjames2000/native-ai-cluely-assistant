# Security Policy

_Last updated: 2026_

We take the security of this project seriously and appreciate reports from researchers, users, and the community.

---

## Supported Versions

Security fixes are issued for the current active branch and releases on GitHub.

---

## Reporting a Vulnerability

If you discover a security issue or vulnerability, please **do not report it through public GitHub issues or public channels**.

### Where to Send Reports
Please report security advisories privately via GitHub repository Security Advisories:
[GitHub Security Advisories](https://github.com/jeevanjames2000/native-ai-cluely-assistant/security/advisories)

### What to Include
Please include:
1. **Description of the issue** (type of vulnerability, affected component, and impact).
2. **Steps to reproduce** (including environment, OS version, or proof of concept).
3. **Suggested mitigation** (if available).

### Response Process
- We will evaluate the report and work towards addressing confirmed issues in an upcoming release.
- Fixes and security advisories will be published on the [GitHub repository](https://github.com/jeevanjames2000/native-ai-cluely-assistant).

---

## Scope

In-scope areas include:
- IPC bridge communication between Electron renderer and main processes
- Audio and screen capture privacy boundaries
- Local key storage and credential management
- Local SQLite database and file parsing utilities

---

## Contact

For security-related inquiries, please open a private security advisory on GitHub.
